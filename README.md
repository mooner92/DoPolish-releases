# Do Polish 설치 파일 (Windows)

기관 문체를 배워 보고서 초안을 다듬고, 사실이 바뀐 수정은 걸러 내는 **Do Polish** 데스크톱 앱의 배포 저장소입니다.
이 저장소에는 **설치 파일만** 올립니다(소스 코드는 없습니다). 앱의 '업데이트 확인'이 이 저장소의 최신 릴리스를 봅니다.

## 받기

[최신 릴리스](https://github.com/mooner92/DoPolish-releases/releases/latest)에서 고릅니다.

| 파일 | 쓰임 |
|---|---|
| `DoPolish-Setup.exe` | 설치본. 설치하면 앱이 새 판을 스스로 받습니다 |
| `DoPolish-Portable.exe` | 무설치 실행본. 자동 업데이트는 되지 않습니다 |

- **정식 판**: `v1.1.1`처럼 붙임표 없는 태그(Latest)
- **미리 보기 판**: `v2.0.0-beta.1`처럼 붙임표가 든 태그(Pre-release). 정식 판 사용자에게는 자동으로 가지 않습니다

`latest.yml`·`*.blockmap`은 자동 업데이트용 파일이라 직접 받을 필요가 없습니다.
