# 공식 기관 스타일

Do Polish 앱이 '공식 기관 스타일'로 받아 가는 스타일 팩입니다(앱 2.0.0-beta.4부터). 사람이 직접 받을 필요는 없습니다.

- `index.json`: 목록(기관·문서 형식·판 번호·규칙 수·묶음 해시). 앱이 켤 때와 한 시간마다 확인합니다.
- `bundles/*.json`: 스타일 하나씩의 묶음(`dop-style/1`, 원내 공유와 같은 형식). 받은 뒤 해시를 확인하고 설치합니다.

규칙은 NKIS(국가정책연구포털)에 공개된 각 기관 발간본(2년치)에서 뽑았습니다. 로컬 모델이 관찰하고, 코드 게이트(학습·시험 7:3)와 Claude haiku·sonnet·opus 검증, 쓰지 않은 시험 문서의 오탐 검사를 거쳤습니다. '강제' 표시는 사람 승인 전 후보입니다. 예문은 해당 기관 발간본에서 짧게 인용했습니다.
